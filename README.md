## Why This Skill Exists (DPDP Act 2023 + DPDP Rules 2025 `G.S.R. 846(E)`)

Modern websites rarely consist of static HTML alone. Marketing tags, Customer Data Platforms (CDPs), Session Replay recorders, AI Chatbots, and Auto-Advanced Matching Ad Pixels frequently execute in the visitor's browser *before* any Consent Notice is displayed or accepted.

Under India's **Digital Personal Data Protection Act, 2023 (Act No. 22 of 2023 — 9 Chapters, 44 Sections, 1 Schedule)** and the **Digital Personal Data Protection Rules, 2025 (`G.S.R. 846(E)`, notified 13 November 2025 — 23 Rules, 7 Schedules)**:

1. **Section 5 & Rule 3 (Standalone, Itemised Notice):** Websites must present an independently understandable notice itemising the personal data collected and the specific purpose before or at the time of requesting consent.
2. **Section 6 & Rules 3–4 (Consent & Symmetry):** Pre-consent non-essential tracking cookies, storage keys, and behavioural pixels require affirmative consent with symmetrical withdrawal ease.
3. **Section 10(2)(c)(ii) & Rule 13(1)–(3) (Annual DPIA & Algorithmic Software Risk Verification):** Significant Data Fiduciaries (and privacy-forward organisations conducting proactive DPIAs) must conduct an annual Data Protection Impact Assessment and verify that **algorithmic software, automated profiling scripts, session replay tools, and AI chatbots** deployed on their digital properties do not pose a risk to the rights of Data Principals.
4. **Section 8(5), Rule 6 & Rule 8(3) read with the Seventh Schedule (Security Safeguards & 1-Year Log Retention):** Websites must enforce transport encryption (`HTTPS`/`HSTS`), Content Security Policy (`CSP`), Subresource Integrity (`SRI`), and retain traffic/access logs for a **minimum of 1 year**.
5. **Section 9 & Rules 10–11 read with the Fourth Schedule (Children's Data):** Strict prohibition on tracking, behavioural monitoring, or targeted advertising directed at children (under 18 years).
6. **Section 13 & Rule 14(3) (Grievance Redressal SLA):** Published Data Protection Officer (DPO) / Grievance Officer contact details and a published grievance resolution period not exceeding the **90-day statutory maximum**.
7. **Section 16 & Rule 15 (Cross-Border Data Transfers):** Full inventory of external third-party script hosts, CDNs, and cross-border sub-processor endpoints.

## 1-Minute Quick Start

### 1. Clone the Repository

```bash
git clone https://github.com/Cyarun/dpdpa-website-dpia-skill.git
cd dpdpa-website-dpia-skill
```

### 2. Run a Passive Read-Only Website Telemetry & Automation Audit

```bash
# Audit any live website URL (100% passive GET + DOM/header/cookie/automation analysis)
node scripts/collect_website_dpia_telemetry.mjs "https://dpdpa.support" \
  --out "/tmp/dpia-telemetry-report.json" \
  --model "claude"
```

### 3. Use With Your Preferred AI Coding Agent or LLM

#### A. Claude Code (`/.claude/skills/website-dpia-audit`)
Copy `.claude/skills/website-dpia-audit/SKILL.md` into your workspace's `.claude/skills/website-dpia-audit/SKILL.md`, then invoke inside Claude Code:
```text
Run the website-dpia-audit skill on https://your-company.example and generate a Reputation-Safe DPDP Act 2023 + Rules 2025 (G.S.R. 846(E)) DPIA Readiness Report.
```
Or pair the telemetry JSON directly with [`prompts/claude-dpia-prompt.md`](./prompts/claude-dpia-prompt.md).

#### B. Google Antigravity / Gemini CLI (`/.agents/skills/website-dpia-audit`)
Copy `.agents/skills/website-dpia-audit/SKILL.md` into your workspace's `.agents/skills/website-dpia-audit/SKILL.md` (or pass [`prompts/gemini-dpia-prompt.md`](./prompts/gemini-dpia-prompt.md) with `responseMimeType: "application/json"`).

#### C. Cursor IDE
Add `.agents/skills/website-dpia-audit/SKILL.md` and `prompts/universal-dpia-system-prompt.md` to your Cursor context (`@SKILL.md`), run the telemetry collector script in the terminal, and ask Cursor to synthesize the executive DPIA report.

#### D. DeepSeek (`DeepSeek-R1` / `DeepSeek-V3`)
Feed the output of `collect_website_dpia_telemetry.mjs` into [`prompts/deepseek-dpia-prompt.md`](./prompts/deepseek-dpia-prompt.md), then pass the model output (including any `<think>...</think>` reasoning blocks) through our deterministic normalizer:
```bash
node scripts/parse_multimodel_dpia_response.mjs \
  --input "/tmp/raw-deepseek-output.txt" \
  --model "deepseek" \
  --out "/tmp/validated-dpia-report.json"
```

#### E. Alibaba Qwen (`Qwen-2.5` / `Qwen3` / `QwQ`)
Feed the telemetry JSON into [`prompts/qwen-dpia-prompt.md`](./prompts/qwen-dpia-prompt.md) and validate with `scripts/parse_multimodel_dpia_response.mjs --model qwen`.
